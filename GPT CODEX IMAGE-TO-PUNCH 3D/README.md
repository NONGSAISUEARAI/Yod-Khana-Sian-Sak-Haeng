# Facade Studio — Area workspace

ฐานระบบออกแบบพื้นที่ติดตั้งฟาสาดหลายด้าน เวอร์ชันแรกนี้สร้างใหม่แยกจาก Image to Punch

## เปิดใช้งาน

ใช้ Node.js รัน `node server.mjs` แล้วเปิด http://127.0.0.1:4173 หรือใช้ `npm start`
ต้องเปิดผ่าน HTTP server เพื่อให้ JavaScript modules ทำงาน ไม่ใช้การดับเบิลคลิก HTML โดยตรง
ไลบรารี Three.js 0.180.0 อยู่ใน vendor แล้ว ไม่ต้องเชื่อมต่อ CDN ตอนใช้งาน

## ทำได้ในรุ่นนี้

- ฉาก 3D หลาย Area: เลือกผิว หมุน เลื่อน ซูม Fit all และดูตรงระนาบ Area
- สร้างพื้นที่สี่เหลี่ยมพร้อมพิกัดและทิศทาง แก้ขอบเขตเป็น polygon เส้นตรง
- ช่องเปิดสี่เหลี่ยม และช่องเปิด polygon จาก DXF ตรวจเส้นตัดกัน/ช่องเปิดทับกัน
- ย้าย Area ด้วยพิกัดโลก และหมุนรอบแกนโลก Z ที่จุดฐานของ Area
- ตั้ง Pattern Origin แยกแต่ละ Area ด้วย Local X/Y หรือคลิกบนผิว พร้อม snap มุม/ขอบ
- ตั้งมุมแกน Pattern หรือคลิกเลือกขอบให้แกน X ขนาน มีกริดอ้างอิงที่ถูกตัดตาม Area/ช่องเปิด
- บันทึก/เปิด JSON project, auto-save ใน browser เดิม และ Undo สูงสุด 40 ขั้น
- มีตัวอย่างฟาสาด 3 ด้าน และ samples/facade-boundaries.dxf สำหรับทดลอง

พิกัดทั้งหมดเป็น mm, โลกใช้ Z ขึ้น, Local X/Y อยู่บนผิวแต่ละด้าน จุดฐานคือจุดแรกของขอบเขตตอนสร้าง/นำเข้า
Pattern Origin อาจอยู่นอก Area ได้เพื่อใช้อ้างอิงกริด แต่การคลิกตั้ง Origin ทำบนเนื้อผิว
Grid spacing ในรุ่นนี้เป็นกริดอ้างอิงเท่านั้น ยังไม่มีลาย Hatch หรือรู Punch

## DXF import contract

- ASCII DXF: closed LWPOLYLINE, closed POLYLINE (2D/3D), และ 3DFACE
- ขอบเขตเส้นตรง, หนึ่งวงต่อหนึ่ง Area, ต้องอยู่บนระนาบเดียวกัน (tolerance 0.05 mm)
- Layer `FRONT` สำหรับขอบนอก และ `FRONT__OPENING` สำหรับช่องเปิดของขอบนั้น
- ช่องเปิดต้องอยู่ภายในอย่างสมบูรณ์ ถ้าแตะขอบให้ทำรอยเว้าใน polygon ขอบนอก
- อ่าน $INSUNITS (mm/cm/m/in/ft) หรือเลือกหน่วยเองก่อนนำเข้า
- รายงานวัตถุที่ข้ามก่อนยืนยันเพิ่ม Areas; ไม่เดาความหมายของเส้นที่นำเข้าไม่ได้
- ยังไม่รองรับ bulge/ARC/SPLINE, BLOCK/INSERT, mesh, curved surfaces หรือรวมหลาย 3DFACE เป็นผิวเดียว
- ไฟล์ไม่เกิน 20 MB และโปรเจกต์ไม่เกิน 200 Areas; เน้นไฟล์ขอบเขต ไม่ใช่โมเดลอาคารเต็ม

## ขอบเขตระยะถัดไป

ยังไม่รวม Image to Punch, การเชื่อม Origin/คลี่ลายข้ามด้าน, Hatch, DXF สำหรับผลิต, การเชื่อมต่อ GLB/SketchUp และการออกแบบผิวโค้ง

## Command line

พิมพ์คำสั่งที่แถบด้านล่าง หรือเริ่มพิมพ์เมื่อโฟกัสอยู่ในฉาก 3D:

- `SELECT` / `S`: เลือก Area ด้วยเลขลำดับ ชื่อตรงกัน หรือคลิกผิว
- `MOVE` / `M`: เลือกจุดฐาน (Enter ใช้ฐาน Area) แล้วจุดปลาย
- `ORIGIN` / `O`: ตั้ง Origin ด้วย Local X,Y หรือคลิกบนผิว
- `ROTATE` / `RO`: เลือกจุดหมุนแล้วระบุมุม รอบ World Z
- `DIST` / `DI`: เลือกสองจุดเพื่อวัดระยะ 3D และระยะแต่ละแกน
- `UCS WORLD` / `UCS LOCAL`: สลับพิกัด World หรือแกนของ Area
- `UNDO` / `U`, `ZOOM` / `Z` → `E` / `S`, `AREA`, `IMPORT`, `ALIGN`, `SAVE`, `HELP`

พิกัด `1000,2000,0` เป็นตำแหน่งสัมบูรณ์ในแกนที่เลือก และ `@1000,0,0` เป็นระยะจากจุดฐาน/จุดก่อนหน้า ใน Local พิกัด Z คือระยะตั้งฉากออกจากผิว Origin ต้องมี Local Z = 0

F3 เปิด/ปิด OSNAP มุมและขอบของ Area ที่เลือก, F8 เปิด/ปิด ORTHO สำหรับจุดที่คลิก ส่วนพิกัดที่พิมพ์ใช้ค่าที่ป้อนตรง ๆ จุดที่ Snap ได้มีลำดับก่อน ORTHO
การคลิกจุด Move/Dist ใช้ระนาบขนานกับ Area ผ่านจุดฐาน หากต้องการระยะออกจากผิวให้พิมพ์พิกัด 3D
Esc ยกเลิกคำสั่ง, Enter ว่างเมื่อไม่มีคำสั่งเรียกคำสั่งล่าสุด, ↑/↓ ดูประวัติการป้อน

## DXF export สำหรับ CAD

กด Export DXF หรือใช้คำสั่ง EXPORT / DXF จะได้ ASCII DXF R2000 หน่วย mm รวมทุก Area แม้ปิดการแสดงอยู่
ขอบเขตและช่องเปิดเป็น Closed 3D Polyline แยก Layer AREA_001, AREA_001__OPENING ฯลฯ
ไม่รวมกริดอ้างอิง ลูกศร Origin หรือรูเจาะลงในแบบ CAD
ชื่อ Area, ID และ Pattern Origin/angle/spacing เก็บเป็น XDATA ของแอป FACADE_STUDIO บน Polyline ขอบนอก
เมื่อนำกลับเข้าเว็บจะคืนค่าจาก XDATA หากโปรแกรม CAD ยังคงข้อมูลนี้ไว้ (Explode/สร้างเส้นใหม่หรือเครื่องมือที่ลบ XDATA อาจทำให้ข้อมูลนี้หาย)
Origin อ้างอิงจากจุดแรกและเส้นช่วงแรกของวงขอบเขต การเปลี่ยนลำดับจุดหรือ Scale ใน CAD อาจต้องตั้ง Origin/spacing ใหม่
ไฟล์ JSON จาก Save project ยังเป็นสำเนางานเว็บที่เก็บครบกว่า รวมสถานะการมองเห็น
การนำ DXF กลับเข้าใช้ Add areas ตามปกติ ไม่ใช่แทนที่หรือซิงก์งานเดิมอัตโนมัติ ID ที่ซ้ำกับงานปัจจุบันจะสร้างใหม่เพื่อให้บันทึกโปรเจกต์ต่อได้

## Curtain Wall รุ่นแรก

เลือก Area แล้วเปิด Properties > Curtain Wall > Enable on this area หรือพิมพ์ CURTAIN / CW
ระบบมี Curtain Origin และ Curtain axis angle แยกจาก Pattern Origin พร้อม spacing X/Y แยกจาก reference grid งานเดิมที่ยังไม่เคยตั้ง Curtain Origin จะอ้างอิง Pattern Origin จนกว่าจะกำหนดค่าแยก
ตั้ง spacing, gap, ความหนาและสีแผ่น, ขนาดหน้าตัด Mullion, offset ตาม Normal ของ Area และเปิด/ปิดกรอบขอบนอก/ช่องเปิด
เพิ่มแนวแบ่งเองด้วย Extra X/Y เป็นระยะจาก Origin บนแกนกริด คั่นด้วย comma เช่น 750, 2500
แผ่นและหน้าตัดโครงตัดตาม polygon ของ Area และช่องเปิดจริง รองรับรูปเว้าและกริดเอียง
คลิกช่องแผ่นเพื่อเลือก แล้วเปลี่ยนเป็น Solid / Glass / Open เฉพาะช่องได้ สูงสุด 100 overrides ต่อ Area
Show panels/grid/mullions เป็นการแสดงผลแยกกัน ไม่เปลี่ยนค่ารูปทรงหรือชนิดแผ่น
แสดงจำนวนช่อง พื้นที่แผ่นสุทธิ และความยาวเส้นกลางโครง รวมกรอบรอบช่องเปิดตามตัวเลือก
ค่าระบบและ overrides เก็บใน JSON project และ XDATA เมื่อ Export DXF; DXF ยังแสดงเฉพาะขอบเขต Area/ช่องเปิด ไม่ส่ง geometry ของ Panel/Mullion เป็นแบบผลิต
การย้าย Origin หรือปรับกริดอาจทำให้ override บางช่องไม่ตรงกับช่องใหม่ ให้ Reset panel overrides เมื่อต้องการเริ่มใหม่
มีขีดจำกัด 1,000 cells ต่อ Area และรวม 5,000 panels / 10,000 members เพื่อรักษาความลื่นของพรีวิว
ยังไม่มีการเชื่อม/เข้ามุมโครงข้าม Area, หน้าตัดซับซ้อน, การลากเส้นกริด หรือการออกแบบจุดยึด
polygon-clipping 0.15.7 ใช้ MIT license ใน vendor/POLYGON-CLIPPING-LICENSE.md



ตั้ง Curtain Origin ที่ Properties > Curtain Wall ด้วย Local X/Y หรือ Pick curtain origin พร้อม Snap ตามปุ่ม F3
แกน Curtain Origin แสดงสีฟ้าแยกจากแกน Pattern เดิม ตั้ง Curtain axis angle ได้โดยไม่เปลี่ยนมุม Pattern
Use Pattern Origin เป็นการคัดลอกจุดและมุมปัจจุบันมาใช้ ไม่เชื่อมให้เปลี่ยนตามในภายหลัง
ค่าจุดเริ่มและมุมนี้บันทึกใน JSON และ XDATA ของ DXF รวมถึงแปลงตามระนาบขอบเขตเมื่อนำเข้ากลับ

## Multi-Area Curtain Wall

Ctrl+คลิกในรายการหรือบนผิวเพื่อเพิ่ม/เอา Area ออกจากชุดที่เลือก คลิกปกติเลือกด้านเดียว
All / Ctrl+A (เมื่อไม่ได้พิมพ์ในช่องข้อมูล) เลือกทุก Area; Clear ยกเลิกทั้งหมด
ค่าที่แก้ในหมวด Curtain Wall รวมถึงคำสั่ง CW ใช้กับทุก Area ที่เลือก โดยเปลี่ยนเฉพาะ field นั้นและเก็บค่าอื่นของแต่ละด้านไว้
ค่าที่ต่างกันแสดง Mixed หรือ checkbox indeterminate; สถิติ Panel/โครงรวมทั้งชุดที่เลือก
การแก้ชุดหนึ่งเป็น Undo ครั้งเดียว ตรวจข้อมูลทุกด้านและขีดจำกัดฉากก่อน commit ไม่มีการเปลี่ยนบางด้านค้างไว้เมื่อไม่ผ่าน
Origin X/Y แบบกลุ่มเป็นพิกัด Local ของแต่ละด้าน Use each Area’s Pattern Origin คัดลอกจาก Pattern ของด้านนั้นเอง
การคลิกตั้ง Curtain Origin และแก้ Panel เฉพาะช่องใช้เมื่อเลือก Area เดียวเท่านั้น
Properties หมวดอื่นและคำสั่ง Move/Rotate ยังแสดง/แก้เฉพาะ active Area ที่ระบุในข้อความแจ้ง ไม่ใช่ transform กลุ่ม
รายการ Area ที่เลือกเก็บในโปรเจกต์และ auto-save แต่การแก้ค่าร่วมกันครั้งนี้ไม่สร้างกลุ่มลิงก์ถาวร
